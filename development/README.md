# Development stage: raw material (archive side)

Everything raw that the style-development stage produces lives HERE, never in the new project:
tutorial downloads/links, transcripts, extracted frames, measurements, notes, experiments, test renders, comparisons.

One folder per item: `development/<YYYY-MM-DD>_<topic>/` containing
- `source.md`: where it came from (link/file, author, date) and what it is
- the raw files (transcript, frames, data, test outputs)
- `notes.md`: everything learned, including what did NOT work

When a point is proven (tested, and the user agrees), only its CONCLUSION (the "source": one clear rule or setting) is written into
the new project `C:\Users\hp\Desktop\2.5D animation\brain\` (the right chapter, in place) and logged in its `brain/CHANGELOG.md`
with a pointer back to the folder here.
